# 出力フォーマット

ひな形ブックの1シートを複製して、ヘッダー部と作業履歴を差し替える。
罫線・フォント（ＭＳ Ｐゴシック）・注記文はひな形を踏襲する。

## シート構成

```
A1               栽培履歴
E2/F2            圃場名
E3/F3            年度
A4               生産行程管理責任者　<氏名>          J4  作成日
A6/B6            圃場名（面積つき）      E6  苗・種の使用数 ┐ 可変ブロック
A7/B7            栽培面積                F6..J6 作物/品種   │ 5組ずつ
A8/B8            責任者                  F7..J7 使用数      ┘ 折り返す
A10:D11          アルバイト・体験参加者への周知の注記
                 E  肥料の使用量 / 使用資材 / 使用機械 / 注記
（1行あけて）
月日 | 作物/品種 | 作業内容 || 月日 | 作物/品種 | 作業内容
```

## 苗・種の使用数

- **作物と品種の組合せごと**に1枠。同じ作物でも品種が違えば分ける（ニンニク3種など）
- 定植・播種の記録から集計。播種は「粒」、定植は「本」
- **日誌に数量がない枠はクリーム色 `FFF2A8` で塗る**。空欄のまま流さない
- 5組を超えたら2行1組のブロックを下へ増やす（21組=5段まで実績あり）

## 肥料・資材・機械

- **肥料は種類のみ。使用量・希釈倍率は載せない**（直近の運用）
- 防除資材（ボルドー液など）は肥料ではなく「使用資材」へ
- 資材欄に機械名が書かれている行がある（管理機など）→ `materialToMachine` で機械へ回す
- 5枠に収まらない分は最後の枠へ `、` でまとめる

## 作業履歴

- 作業内容から**数量・希釈倍率を落とす**（`300倍` `17袋` `1.8反`）。肥料名は残す
- `施肥 コアユーキエキス：300倍　K3：10000倍` → `施肥(コアユーキエキス、K3)`
- 同じ日・同じ作物・同じ作業内容は1行にまとめる
- 圃場欄に記録された事務・出荷作業（発送・掃除・パック・冷凍庫など）は除外し、
  **除外した一覧を必ずユーザーに報告する**
- 件数が多い圃場（100件超）は左右2ブロックに分けて流し込む

## 休耕シート

耕作履歴が無い圃場、または造成工事しか記録が無い圃場は
作業内容欄に「当年度は休耕(不作付)。栽培作業実績なし。」と記載し、注記欄にも同旨を書く。

## 印刷設定

- A4横・`fitToWidth=1` / `fitToHeight=0`（縦は複数ページを許す）
- `print_title_rows` で見出し行を各ページに繰り返す
- 余白 0.4inch
