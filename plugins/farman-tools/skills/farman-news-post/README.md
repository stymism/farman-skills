# farman-news-post

farman.jp（自社サイト）のWordPress「お知らせ」に記事を一括登録するスキル。プレスリリース（PR TIMES）・メディア掲載・TV放映・講演/登壇・イベント参加などを、既存記事の書式に合わせて下書き/公開する。

手順の詳細は [`SKILL.md`](./SKILL.md) にある。**この README は概要・起動条件・変更履歴のみ**を扱う。

- **プラグイン**: `farman-tools`
- **正本**: `C:\claude code\skills-marketplace\plugins\farman-tools\skills\farman-news-post\`
- **取り込み**: `claude plugin update farman-tools@farman-skills`

## 起動するとき

「farman.jp のお知らせに追加」「WordPressに載せて」「プレスリリースを掲載」「〇〇が放映/掲載されたのを追加」「井上代表の登壇を追加」など。URL一覧を渡された場合や「お知らせを更新したい」だけの場合も含む。

## SKILL.md の構成

- 前提の確認
- 全体の流れ
- 大事な注意（ハマりどころ）
- 出力（ユーザーへの報告）
