# strategy-council

議事録を1つ渡すだけで、複数のAIエージェントが分業して戦略レポートまで作るスキル。**戦略を全否定するレッドチームとの自動問答**を挟むのが最大の特徴。

手順の詳細は [`SKILL.md`](./SKILL.md) にある。**この README は概要・起動条件・変更履歴のみ**を扱う。

- **プラグイン**: `strategy-suite`
- **正本**: `C:\claude code\skills-marketplace\plugins\strategy-suite\skills\strategy-council\`
- **取り込み**: `claude plugin update strategy-suite@farman-skills`
- **Cowork**: ⭕ 動く（Agentツールが使える環境なら。作業フォルダはカレント配下の `Strategist/` になる）

## 出力先

```
OneDrive\ドキュメント\farman\Strategist\<案件名>\YYYY-MM-DD\
```

全案件を `Strategist` に集約し、**案件ごとに検討が積み上がる**。同じ案件を再検討すると、前回の最終レポートを引き継いで走る。

## 起動するとき

「戦略を作って」「この議事録から戦略に落として」「戦略会議して」「AIエージェントで分業して戦略検討」「レッドチームにかけて」「この戦略を潰して」など。

## 工程

```
Step 1   議事録取得（Plaud / Notion / ローカル・貼り付け）
Step 2   イシュー構造化
Step 3   並列リサーチ ×3（市場競合 / アナロジー事例 / 顧客）← 同時実行
Step 4   ストラテジスト統合（3案 → 1案推奨）
Step 4.5 ★レッドチーム問答（自動でラウンド数決定・上限4）
Step 5   レビュー＆最終レポート
```

エージェント8〜13体、10〜25分。

## 設計の要点

- **エージェント同士は会話できない** ので、成果物は全部ファイル経由。中断・再開・部分実行が効く
- **否定役にイシュー構造を渡さない** — 戦略役のフレーミングを引き継がせると「その枠内の批判」しか出ない
- **否定役は代替案を出さない・褒めない** — 代案を書いた瞬間に否定が甘くなる
- **反証条件を必ず書かせる** — 「これを覆すには何を示せばよいか」があるから戦略役が答えられる
- **手加減の検出** — R1で Fatal 0 なら収束と見なさず、強度最大で必ずもう1ラウンド回す
- **骨抜きの検出** — 否定に応え続けると戦略は無害化する。レビュワーが専門に見る
- **否定役が勝つこともある** — 無理に戦略を通さない。それが機能している証拠

## 近いスキルとの使い分け

| | 使う場面 |
|---|---|
| **strategy-council** | 固まった案を**AIが殴って**鍛える（多エージェント・自動） |
| `grill-me` | これから作るものの前提を**人間に聞いて**固める（一問一答） |
| `take-a-step-back` | 進行中の議論から一段引いて軌道を点検する |
| `brain-dump` | 未整理の塊を吐き出して構造化する |

`brain-dump`（発散）→ `grill-me`（人間に詰める）→ **`strategy-council`（AIが殴る）**→ `distribution-check`（社外に出す前）。
