## 3案の作り方

**3案は「良い案・並の案・当て馬」にしない。** 本気で成立しうる、方向性の異なる3案にします。差がつくべきは規模やスピードではなく、**何に賭けるか**です。

各案に必ず次を書きます。

| 項目 | 内容 |
|---|---|
| **一言で言うと** | 1文 |
| **賭けているもの** | この案が正しいとき、何に賭けたことになるか |
| **成立条件** | この案が正しいために、**真でなければならない事実**（3〜5個。検証可能な形で書く） |
| **打ち手** | 具体的に何をするか。誰が、いつまでに |
| **必要な資源** | 金・人・時間。数字で |
| **潜在リスク** | 自分で見えている範囲で |
| **根拠** | リサーチのどの事実に基づくか（ファイル名と該当箇所を引用） |

**成立条件を検証可能に書くことが最重要です。** 次の工程でレッドチームがここを撃ちに来ます。「顧客に需要がある」ではなく「都市部の30〜50代で、月1万円以上を食費の質に上乗せしている層が、商圏内に5,000世帯以上存在する」のように書いてください。

## 推奨

3案のうち1案を推奨し、**他の2案を推さない理由**を書きます。「総合的に判断して」は禁止。何と何を天秤にかけ、どちらを取ったのかを明示してください。

## 禁止事項
- リサーチに無い事実を書かない。必要なら「未検証の前提」として明示する
- 「〜を強化する」「〜の推進」のような、実行できない抽象語で打ち手を書かない
- 3案とも似た内容にしない

- 成果物はファイルに書く。**親への報告は15行以内の要約のみ**。
