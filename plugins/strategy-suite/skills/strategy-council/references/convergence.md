# Step 4.5 の収束判定

ラウンド数を自動で決めるための規則。**判定するのは親セッションであり、エージェントに判定させない。** エージェントは自分の仕事が終わったかどうかを判断できる立場にない。

## 1ラウンドの手順

```
1. 否定役をスポーン           → 04_redteam_Rn.md
2. 親が指摘を格付け・集計       → 下の「集計のしかた」
3. 戦略役をスポーン            → 05_反論_Rn.md
4. 親が継続判定                → 下の「継続判定」
5. 続けるなら n+1 で 1 へ
```

## 集計のしかた

否定役の出力から、**新規の** Fatal / Major / Minor を数える。

### 重複の除き方
前ラウンドと**同じ論点の言い換え**は新規に数えない。判定は親が行う。次のどれかに当たれば「同一論点」とみなす。

- 撃っている成立条件が同じ
- 反証条件が実質同じことを要求している
- 前ラウンドで「受容」「修正」済みの指摘の蒸し返し（ただし**修正によって新しく開いた穴**は新規である）

### 差し戻しの条件
次に当たる指摘は、集計に入れる前に否定役へ差し戻す（同じラウンド番号で再スポーン）。

- **反証条件が書かれていない** — 相手が答えられない指摘は議論にならない
- **代替案を提案している** — 役割の混線
- **緩衝表現がある**（「一方で良い点は」等） — 立場が崩れている
- **全件が Fatal** — 格付けの意味が消えている

## 継続判定

| 状態 | 判定 |
|---|---|
| 未解決の Fatal が1件以上 | **続ける** |
| このラウンドで 新規Fatal + 新規Major が2件以上 | **続ける** |
| Fatal 0件 かつ 新規Major 1件以下 | **抜ける**（ただしラウンド1は下記の手加減検出へ） |
| 4ラウンド到達 | **打ち切る**。未解決分は最終レポートの「未解決論点」に明記 |

「未解決の Fatal」とは、直前の `05_反論_Rn.md` で **保留** ラベルが付いたもの、および **反論** とされたがレビュワー観点で反証条件に答えていないものを指す。

## 手加減の検出（必ず実施）

**ラウンド1で Fatal 0 かつ Major 1件以下だったときは、収束と判定してはならない。**

戦略が強いのではなく、否定役が同調した可能性のほうが高い。LLM は文書を褒める方向に流れやすく、「否定しろ」という指示だけでは1回目に手加減が出る。次の条件を足して**もう1ラウンド必ず回す**。

- プロンプトに `強度: 最大` を指定
- `攻撃軸` に、ラウンド1で使っていない軸を明示的に指定（特に **6. 反証事実の探索** と **2. 経済性** は手加減が出にくい）
- 「前回の指摘は弱すぎた。この戦略には必ず致命的な欠陥があるという前提で読め」を冒頭に追加

これでも Fatal 0 なら、本当に収束したと見なしてよい。**その事実自体を最終レポートに書く**（「2ラウンドの攻撃で致命的欠陥は出なかった」は情報である）。

## 発散の検出

逆に、ラウンドを重ねても Fatal が減らない場合がある。3ラウンド目で未解決 Fatal が2件以上残っているなら、**それは戦略の問題ではなく前提の問題**である可能性が高い。この場合は問答を止めて、次のどちらかを人間に報告する。

- **リサーチ不足** — 決着に必要な事実が無い。Step 3 に戻って追加調査する
- **そもそも成立しない構想** — 早く分かってよかった。最終レポートは「この方向は推奨しない」という結論で書く

**無理に戦略を通さない。** 否定役が勝つこともあるのが、このスキルが機能している証拠である。

## ラウンド数の目安

| ラウンド数 | 意味 |
|---|---|
| 2 | 標準。手加減検出込みの最短 |
| 3 | 戦略が骨太で、攻撃が実質的だった場合 |
| 4（上限） | 決着せず。未解決論点として残す |
