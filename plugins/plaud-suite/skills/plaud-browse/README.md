# plaud-browse

Plaud録音の一覧表示・ページ送りをするスキル。最近のアップロードを眺めるための入口。

手順の詳細は [`SKILL.md`](./SKILL.md) にある。**この README は概要・起動条件・変更履歴のみ**を扱う。

- **プラグイン**: `plaud-suite`
- **正本**: `C:\claude code\skills-marketplace\plugins\plaud-suite\skills\plaud-browse\`
- **取り込み**: `claude plugin update plaud-suite@farman-skills`

## 起動するとき

「どんな録音がある?」「最近の録音を見せて」「録音を一覧して」など。**特定の録音を探す**場合は `plaud-find` を使う。
