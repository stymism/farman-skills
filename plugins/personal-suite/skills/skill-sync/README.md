# skill-sync

スキルの手順・前提・既知の制約に変更や新しい知見が生じたとき、その内容を正本リポジトリの SKILL.md・README.md・関連する他スキルのMDまで漏れなく反映し、commit → push して全PCへ配布するスキル。

**スキルは書きっぱなしにすると必ず実態とズレる。** 実行して分かったこと（罠・仕様変更・手順の誤り）を、その場で正本に書き戻すためのもの。

手順の詳細は [`SKILL.md`](./SKILL.md) にある。**この README は概要・起動条件・変更履歴のみ**を扱う。

- **プラグイン**: `personal-suite`
- **正本**: `C:\claude code\skills-marketplace\plugins\personal-suite\skills\skill-sync\`
- **取り込み**: `claude plugin update personal-suite@farman-skills`

## 起動するとき

「スキル更新して」「この知見を反映して」「MDを最新化して」「skill-sync」など。スキル実行中に「SKILL.mdの記述が実態と違う」「同じ失敗を繰り返した」と気づいた場合は、明示的に言われなくても起動を提案してよい。

具体的なきっかけ：

| きっかけ | 例 |
|---|---|
| 外部仕様の変化を実測した | APIのレスポンス項目が増減した、パラメータの制約が判明した、認証方式が変わった |
| 同じ失敗を2回した | キャッシュで「直っていない」と誤診、文字コード破壊、計測値の誤読 |
| SKILL.mdの記述が実態と違った | 「Aを使え」と書いてあるが実際はAが使えない |
| ユーザーに指摘された | 「それ前も言った」「MDに書いてある通りじゃない」 |

## 全スキルとの関係

このスキルは**全スキル共通ルールの本体**。`skill-sync` 以外の全 SKILL.md の末尾には「🔄 このスキルを更新したら（全スキル共通ルール）」という要約ブロックが埋め込まれており、そこから `/skill-sync` を参照している。

そのため **`skill-sync` 自身には共通ルールブロックを埋め込んでいない**（自己参照になるため）。

## 注意・制約

- **直すのは正本だけ。** 実行時に読まれている `~/.claude-code/plugins/marketplaces/farman-skills/...` は同リポジトリのgitクローン（複製）で、そこを直しても次の `claude plugin update` で消える。
- **編集前に `git pull --rebase`。** 複数PCで編集するため、いきなり編集すると衝突する。
- **push は確認なしで実行する**（2026-07-28 変更。farman-skillsリポへの変更はユーザー承認済み）。
  ただし publicリポジトリのため、**秘密情報が混ざっていないかのスキャンは省略しない**。
  他リポジトリや外部公開を伴う操作は従来どおり確認する。
- **ローカル編集だけで「更新しました」と報告しない。** push して各PCが取り込めて初めて更新完了。
