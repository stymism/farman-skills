# cal-sync

Gmailのスケジュール系メール（予約完了・配達予定・診療予約・宿泊/交通など日付が確定する連絡）を読み、Googleカレンダーに**まだ登録されていない予定だけ**を登録するスキル。

概要欄にメールの要点をメモし、全カレンダー横断で既存予定と照合して二重登録を防ぐ。

手順の詳細は [`SKILL.md`](./SKILL.md) にある。**この README は概要・起動条件・変更履歴のみ**を扱う。

- **プラグイン**: `personal-suite`
- **正本**: `C:\claude code\skills-marketplace\plugins\personal-suite\skills\cal-sync\`
- **取り込み**: `claude plugin update personal-suite@farman-skills`

## 起動するとき

「カレンダー同期して」「予定をカレンダーに入れて」「メールの予定登録して」など。定期稼働（スケジュール経由）でも同じ手順を使う。

## SKILL.md の構成

- 前提
- 登録先カレンダー
- 拾う対象(スケジュール系メール全般)
- 手順
- ルール

## 注意・制約

- **メールの移動・ラベル付けはしない**（読むだけ）。
- 重複チェックは必須。全カレンダー横断で確認する。
