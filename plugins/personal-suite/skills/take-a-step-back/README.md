# take-a-step-back

会話の途中で細部から一段引いて全体像を見直すスキル。大局の視点・ギャップ分析・振り返りの問い・バイアスチェック・自分の文脈との整合、の5観点で点検する。

手順の詳細は [`SKILL.md`](./SKILL.md) にある。**この README は概要・起動条件・変更履歴のみ**を扱う。

- **プラグイン**: `personal-suite`
- **正本**: `C:\claude code\skills-marketplace\plugins\personal-suite\skills\take-a-step-back\`
- **取り込み**: `claude plugin update personal-suite@farman-skills`

## 起動するとき

「一回引いて」「俯瞰して」「これ深掘りしすぎ?」「方向合ってる?」など。細部の議論が10ターン以上続いて戦略チェックが入っていないとき、手詰まり感や苛立ちが見えるときにも提案してよい。
