# grill-me

計画・意思決定・アイデアについて、一問一答で徹底的に問い詰めるスキル。不可逆な決定から順に潰し、各質問に推奨回答と「外したときのコスト」を添え、共通理解に達するまで実行に移らない。

手順の詳細は [`SKILL.md`](./SKILL.md) にある。**この README は概要・起動条件・変更履歴のみ**を扱う。

- **プラグイン**: `personal-suite`

- **取り込み**: `claude plugin update personal-suite@farman-skills`

## 起動するとき

「詰めて」「グリルして」「壁打ちしたい」「質問攻めにして」「要件を詰めよう」「grill me」など。曖昧なまま実装を始めさせようとしているときにも提案してよい。

## 4つの規則（要点）

1. 質問は一度に一つ、回答を待つ
2. 各質問に推奨回答＋外したときのコストを添える
3. 調べれば分かる事実は自分で調べる（決定はユーザーのもの）
4. ユーザーが共通理解を確認するまで実行しない

## 特徴

- **深さを最初に合わせる** — ざっと(5問) / しっかり(10〜20問) / 徹底
- **不可逆な決定から聞く** — 可逆なものは仮決めして飛ばし、その旨を申告
- **進捗ヘッダ** — `[3問目 / 残り5論点 — スコープ]` を毎問表示。論点が増えたら申告
- **「分からない」を3分岐** — 調べる / 仮決めして印を付ける / 「決めない」を決定として記録
- **締めくくりで必ずハンドオフを確認** — 合意を会話ログに埋もれさせない

## 近いスキルとの使い分け

`brain-dump`（発散）→ **`grill-me`（収束）**→ `handoff`（受け渡し）→ 実装。
軌道そのものを点検したくなったら `take-a-step-back`（俯瞰）へ。

| | 使う場面 |
|---|---|
| **grill-me** | これから作るものの前提を、着手前に固める（前向き・一問一答） |
| `take-a-step-back` | 進行中の議論から一段引いて軌道を点検する（俯瞰・分析） |
| `brain-dump` | 未整理の塊を吐き出して構造化する（発散→整理） |
