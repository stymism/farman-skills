# brain-dump

頭の中のごちゃごちゃ（アイデア・タスク・半端な計画）を吐き出したものを、構造化された実行可能な形に整理するスキル。

「プロジェクト&アイデア」「タスク」「つながり（既存の蓄積との接続）」「今すぐできること」の4セクションに再編成する。

手順の詳細は [`SKILL.md`](./SKILL.md) にある。**この README は概要・起動条件・変更履歴のみ**を扱う。

- **プラグイン**: `personal-suite`
- **正本**: `C:\claude code\skills-marketplace\plugins\personal-suite\skills\brain-dump\`
- **取り込み**: `claude plugin update personal-suite@farman-skills`

## 起動するとき

「ブレインダンプ」「頭の中ぶちまける」「考え整理して」「とりあえず吐き出させて」など。**長い未整理の塊を貼っただけでも**、ブレインダンプに見えれば起動してよい（魔法の言葉を待たない）。
