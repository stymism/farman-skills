# ui-styling

shadcn/ui（Radix UI + Tailwind）とTailwind CSSで、アクセシブルなUIを実装するスキル。ダイアログ・ドロップダウン・フォーム・テーブル等のコンポーネント、テーマ/ダークモードのカスタマイズ、レスポンシブ対応を扱う。

`shadcn_add.py` / `tailwind_config_gen.py` のユーティリティスクリプトを同梱する。

手順の詳細は [`SKILL.md`](./SKILL.md) にある。**この README は概要・起動条件・変更履歴のみ**を扱う。

- **プラグイン**: `design-suite`
- **正本**: `C:\claude code\skills-marketplace\plugins\design-suite\skills\ui-styling\`
- **取り込み**: `claude plugin update design-suite@farman-skills`

## 起動するとき

「shadcnで組んで」「Tailwindでスタイリングして」「ダークモード対応して」「アクセシブルなモーダルを作って」など。
