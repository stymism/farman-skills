# brand

ブランドボイス・ビジュアルアイデンティティ・メッセージングフレームワーク・アセット管理を扱うスキル。ブランドの一貫性を保つための参照先とテンプレートを持つ。

`update` / `review` / `create` のサブコマンドで、既存ブランドの更新・レビュー・新規作成を切り替える。

手順の詳細は [`SKILL.md`](./SKILL.md) にある。**この README は概要・起動条件・変更履歴のみ**を扱う。

- **プラグイン**: `design-suite`
- **正本**: `C:\claude code\skills-marketplace\plugins\design-suite\skills\brand\`
- **取り込み**: `claude plugin update design-suite@farman-skills`

## 起動するとき

「ブランドガイドライン作って」「トンマナ揃えて」「このコピーはブランドに合ってる?」など、ブランド準拠のコンテンツ作成・監査。
