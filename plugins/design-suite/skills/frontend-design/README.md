# frontend-design

新規UIの構築や既存UIの作り直しにあたって、テンプレート然としない「意図のあるビジュアル」を作るための指針。美的方向性・タイポグラフィ・判断基準を扱う。

ブレインストーム→探索→計画→批評→構築→再批評 というプロセスを踏む。
